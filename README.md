# PokeCLI 🎮

A command-line Pokedex built with TypeScript that lets you explore the Pokemon world using the [PokeAPI](https://pokeapi.co/).

## Features
- 🗺️ Explore Pokemon location areas
- 🔍 Find Pokemon in specific areas
- 🎯 Catch Pokemon with a random chance system
- 📖 Inspect caught Pokemon's stats and types
- 📦 View your caught Pokemon collection
- ⚡ Built-in caching for fast repeated requests

## Requirements
- Node.js v18+
- TypeScript

## Installation
```bash
git clone https://github.com/YOUR_USERNAME/pokecli.git
cd pokecli
npm install
```

## Usage
```bash
npm run dev
```

## Commands

| Command | Description |
|---------|-------------|
| `help` | Displays a help message |
| `map` | Displays the next 20 location areas |
| `mapb` | Displays the previous 20 location areas |
| `explore <area>` | Lists all Pokemon in a location area |
| `catch <pokemon>` | Attempt to catch a Pokemon |
| `inspect <pokemon>` | View details of a caught Pokemon |
| `pokedex` | Lists all your caught Pokemon |
| `exit` | Exit the Pokedex |
